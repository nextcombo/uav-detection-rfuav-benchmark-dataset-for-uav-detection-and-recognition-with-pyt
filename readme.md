# UAV Detection - RFUAV: Benchmark Dataset for UAV Detection and Recognition [with Python Code]

In this paper, we present RFUAV, a new radio frequency (RF)-based benchmark dataset for unmanned aerial vehicle (UAV) recognition, aiming to address the following challenges: Firstly, many existing datasets have limited types of UAVs and insufficient raw data volumes, failing to meet the needs of practical applications. Secondly, existing datasets often lack raw data covering a wide range of signal-to-noise ratio (SNR), or do not provide tools to convert raw data into different SNR levels, weakening the effectiveness of model training and evaluation. Lastly, many existing datasets do not provide open-access evaluation tools, leading to a lack of unified evaluation standards in the field of current research. RFUAV contains approximately 1.3 TB of raw frequency data collected from 37 different UAVs using a universal software radio peripheral (USRP) device in real environments. Through in-depth analysis of the RF data in RFUAV, we define a UAV feature sequence called RF UAV fingerprint that helps distinguish UAV signals. In addition to the dataset, RFUAV also provides baseline preprocessing methods and model evaluation tools. Rigorous experiments show that these preprocessing methods achieve state-of-the-art (SOTA) performance using the provided evaluation tools.
